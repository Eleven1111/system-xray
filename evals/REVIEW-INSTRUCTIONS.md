# 盲评说明（交给评审的那一份）

> 拿到这份说明和一个 `review/` 目录就可以开始。**不要去看仓库里的其他东西**——
> 尤其不要找哪份是哪条路径产出的。那个映射表故意没放在你手上。

## 你要做什么

`review/` 里有 3 份对**同一个对象、同一份材料**做的分析，标号 `…-P` / `…-Q` / `…-R`。
你要**两两对照**，回答一个问题：

> 相对另一份，这一份有没有**合格的新增洞察**？

对每个"这一份 vs 那一份"的组合各打一个分：

| 分 | 含义 |
|---|---|
| **0** | 仅换措辞／无证据 |
| **1** | 有证据的新解释，但**尚未改变**调查方向或行动 |
| **2** | 有证据，**且明确改变**调查优先级、行动选择或行动条件，并且你能指出它相对另一份新增了哪一步推理 |

**每个分数都必须写理由**，理由要具体到"新增的是哪一步推理"。写不出那一步就不是 2 分。

## 三条硬规矩

1. **不得以长度作为依据。** 三份长短可能差好几倍。更长不等于更好，
   也不等于更差。只看新增的推理步骤，不看字数。
   （组织者手上有篇幅比值，你不需要知道它是多少——知道了反而会变成暗示。）

2. **不得以格式或术语作为依据。** 有的份可能带着框架术语、编号、表格，
   有的可能是平铺直叙。**框架不是洞察**。问的是"它多告诉了你什么可以据以行动的东西"，
   不是"它看起来多专业"。

3. **事实新颖不是必要条件。** 准确重组已有事实、指出两个事实之间此前没人连起来的关系，
   同样可以是 2 分。反过来，堆一个新事实但不改变任何判断，是 0 分。

## 什么算"改变了调查优先级或行动条件"

给几个具体的样子，便于对齐尺度：

- 指出某个结论**依赖一条没被核实的断言**，并说明去核实哪一条能翻转结论 → 改变了调查优先级
- 给出两个解释的**鉴别观察**（若 A 成立而非 B，应额外看到什么）→ 改变了调查方向
- 指出某条建议**超出读者的权限**，并换成读者真能做的事 → 改变了行动选择
- 给出**停止条件**（什么情况下应该放弃这条跟踪）→ 改变了行动条件
- 只是把风险重新排了个序，没说凭什么重排 → 0 分

## 你可能会遇到的两种情况

- **三份都平庸**：全给 0 或 1，这是合法结果。评估不需要谁赢。
- **某份明显更长更细但没多告诉你什么**：给 0。这正是这套判据要拦的东西。

## 交回什么

按 `evals/cases/ratings-template.json` 的结构填，每行一个"案例 × 基线"组合，
`score` 与 `rationale` 都要填。两名评审**各自独立填**，填完之前不要互相看。

分歧由第三位评审按同一判据裁决，裁决理由也要留存。
**无法裁决的按不合格计**——这是预登记规则，不是遗漏。
