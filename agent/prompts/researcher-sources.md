# Researcher 本地语言信源分级表

本文件按语言分节。Orchestrator 在派发 Researcher 时，**只粘贴该批次 `lang` 字段涉及的语言节**，附在 `researcher-base.md` 之后。批次的 `lang` 由 `group_into_batches` 标注。

## 中文 (zh)

| 层级 | 类型 |
|------|------|
| T1 | gov.cn、央行/证监会公告、裁判文书网、巨潮公告 |
| T2 | 财新、澎湃、FT 中文网、第一财经、中国社科院/CIIS |
| T3 | 微博、知乎、脉脉、36氪评论区 |

- 新华社/人民日报：事实报道 T1，社论/评论 T2
- 财新和 FT 中文网优先于其他中文媒体
- 微信公众号视同 T3，除非作者为已知专家/机构
