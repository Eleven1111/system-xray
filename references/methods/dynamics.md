# 方法卡：动态

> 按需加载。适用于跨期更新、时效管理、情景构造、控制论与系统动力学的落地动作。

## 问题

什么在变？这个变化是系统本身变了，还是我们的观测方式变了？变化改变了哪些判断和行动？

## 假设

- **新闻更新不等于机制更新。** 转载不增信；同一事件的重发不是新的系统变化。
- 指标口径变化会伪装成系统改善，反之亦然。
- 反馈延迟意味着"现在看到的"是过去的状态；干预效果同样滞后。

## 观测：四类变化，分类后再更新

| 变化类型 | 例子 | 更新方式 |
|---|---|---|
| 系统状态变化 | 库存下降、退出率增加 | 更新变量与相关判断 |
| 机制变化 | 奖励规则改变、决策权转移 | **重审**相关机制与行动建议 |
| 观测变化 | 指标口径改变、披露制度调整 | **先检查可比性**，不可直接解释为系统变化 |
| 分析修正 | 原文误读被纠正、证据被撤回 | 撤销依赖判断并保留修订记录 |

时间字段至少记：`event_time` / `published_at` / `retrieved_at` / `valid_from`-`valid_to` / `as_of`。
未知时间显式留空。

**时效按断言类型管理**，不是所有材料一个阈值：职位、停运、危机状态需要短时效核验；
组织章程可能长期有效但需检查修订；统计序列看期次、发布日期与修订版本。

## 推论：控制论与系统动力学的具体动作

**控制论**：列出被控过程、目标约束、观测渠道、决策者、执行器、反馈延迟。
重点查两种错配——"**看得见但改不了**"与"**有权但看不见**"。
⛔ 未建立状态空间与模型时，不计算也不宣称严格的可观测性/可控性。

**系统动力学（Meadows）**：区分存量与流量、回路极性、作用延迟与阈值；
干预按种类分层——参数调整 < 信息结构 < 规则 < 目标改变。
⛔ 回路数量和节点度数**不是** Meadows 杠杆等级；强化回路不必然有害，平衡回路不必然有益。
⛔ 回路的好坏方向依赖回路内**全部**维度的状态；有维度未知时只能说极性，不能说好坏。

## 反证

- 局部失效传播检查：某个子系统失效后，哪些判断还成立？
- 边界敏感性：纳入或排除一个重要主体后结论是否改变？改变则报告须写清结论对边界的依赖。
- 触发式复查：只在事实、机制、预测或行动状态变化时才形成更新条目。

## 行动：情景与稳健决策

- 情景由**这个系统**的主要外部冲击、内部机制与可选行动构造，**没有默认三分法**。
  热寂/剧变/涌现是讨论隐喻，不是所有系统的互斥穷尽事件集。
- 只有情景在相同期限内互斥且穷尽、且有可说明的概率依据时，才输出合计 100% 的分布；
  其他情况使用并列条件情景并注明"不构成概率分布"。**允许无法给概率。**
- 深不确定时优先**稳健行动**：哪些选择在多个情景下都可取？设置适应阈值、提前量、
  切换成本与退出路线。
- 先行指标必须带：测量口径、数据源、基线、**阈值来源**、观测频率、误报处理、负责人、对应动作。
  阈值未知标"待校准"，不能从措辞直接生成红黄绿灯。

## 适用限制

- **本 skill 不做持续监测。** 更新发生在用户再次调用时；没有调度器，不要把它描述成能持续监测。
- 临界减速、方差或自相关上升等转变前兆信号，仅在有足够且合适的时间序列、
  明确预处理与模型假设时探索，并需对照无转变时期的误报率。
  相关研究明确讨论了识别限度——**不能套用到短新闻序列**。
- 稳健性也依赖所选情景范围：情景集选窄了，"稳健"是假的。
