# 方法卡：证据

> 按需加载。适用于建立断言账本、判定支撑强度、处理矛盾。
> 结构：问题 → 假设 → 观测 → 推论 → 反证 → 行动 → 适用限制。

## 问题

某条断言获得了多强的支撑？"多条信源"里有几条是独立的？矛盾说明了什么？

## 假设

- 来源身份证明的是**这份材料是谁发的**，不是**它说的内容为真**。
- 转载、翻译、引用共享同一个原始出处的可错性；它们一起错的概率远高于独立观察。
- 声称与效果是两类断言：官方文件能高可靠地证明"规则已发布"，不能独立证明"规则实施效果良好"。

## 观测

每条载荷性断言登记（`claims[]`）：

| 记什么 | 为什么 |
|---|---|
| 原文摘录 + 位置（页码/段落/时间戳） | 让读者能沿一条主张追溯到具体句子，而非只能找到文末来源列表 |
| `source_family` + `lineage` | 折叠转载/翻译/引用，得出**独立来源家族数**——支撑强度的真实分母 |
| `role`（supports / contradicts / background） | 背景链接不构成支撑 |
| `directness`（direct / indirect / inferred） | 同一份材料对不同断言的直接程度不同 |
| `interest` | 观测与发布主体在该断言为真时的利害 |
| `event_time` / `published_at` / `retrieved_at` | 事件时间未知时**显式留空**，不得用检索日期替代 |
| `reachability` vs `status` | 可达性与核验状态是两件事，分开记 |

## 推论

- 独立来源家族 < 2，或最高只有 T3 → 支撑单薄，进独立复核分诊。
- `supported` 的语义是**"在所列材料与口径下获得支持"**，不是永久为真。
- **人物身份类断言强制复核**：现任职位、"从 X 加盟"、任职起始时间、汇报关系——
  一律登记为载荷性断言并无条件复核，哪怕只有单条 T2、哪怕毫无疑点。
  这类事实最廉价可查、最容易自信弄反、错了对报告信誉打击最大。

## 反证

- **改写忠实性比对**：回到信源原句核对**主体、来源、方向**有没有被弄反。
  典型陷阱："A 向 B 汇报 / B 麾下有从 A 挖来的人" → 被改写成 "B 来自 A"；
  "X 据报道将做 Y" → 被改写成 "X 已做 Y"。URL 与数字都对，只有比对原句才拦得住。
- **同源复制检验**：把疑似转载标同一 `source_family` 重算——如果假说排序因此改变，
  原结论建立在重复计数上。

## 行动

对矛盾**作证据判断，不机械"两边都说"**。先区分：

| 冲突类型 | 处理 |
|---|---|
| 时间不同 | 按 `event_time` 排序，多半不是真冲突 |
| 统计口径不同 | 校准口径后再比；口径变化不是系统变化 |
| 翻译错误 / 引用方向错误 | 回原句核对方向，能解决就明确解决 |
| 价值分歧 | 说明这是评价主体不同，不是事实冲突 |
| 真实事实冲突 | 说明剩余分歧及其影响**范围** |

"存在两种说法"不代表二者证据相当；"矛盾更多"也不必然让所有结论置信度更低——
按**受影响的断言和机制**局部调整，不做全局降级。

## 适用限制

- 家族折叠是**保守下限**：未标 `source_family` 的不同措辞转述仍会被当成两族。
  本方法不声称能识别所有转载。
- 账本由同一个可能犯错的流程自报，信源计数是下限不是真相（两个源可能都不支撑该断言）。
- 独立复核者本身也是可能犯错的 LLM，它靠"多源独立求证与原断言冲突"抓错，**不是真相保证**。
- 残余的"自信错断言 + 自信错信源 + 复核者也错"是训练截止后事件的不可消除底噪——
  加门控关不掉。目标是让载荷性断言获得独立第二次求证，不是"准确性已解决"。
